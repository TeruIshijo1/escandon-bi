# Pase a Producción

Directorio que contiene los scripts necesarios para desplegar y ejecutar el proyecto en el entorno de producción.

## Componentes
- `iniciar_produccion.bat`: Script de inicio para levantar servicios.
- `instalar.bat`: Script de instalación de dependencias y configuración.

Estos scripts orquestan el levantamiento tanto del [[Frontend]] como del [[Backend]] con su conexión a la [[Database]] en un ambiente optimizado y preparado para usuarios finales.
